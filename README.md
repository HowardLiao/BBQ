## ✨ 核心特色與功能 (Features)

1. **完整菜單與即時計算**
   - 涵蓋嚴選肉品、海鮮類、鮮甜時蔬、經典串燒/豆製品、飲品酒類等 30 項人氣品項。
   - 每品項支援即時數量調整（+/- 按鈕與手動輸入），自動計算品項小計。
   - 浮動結算欄即時統計總項數、總串數與應付總金額（NT$）。

2. **多維度用餐與客製偏好設定**
   - **用餐方式**：外帶（支援取餐姓名/電話末碼）與內用（支援桌號）。
   - **辣度喜好**：不辣、辣、辣（另放）。
   - **特殊備註**：提供「醬多」、「少醬」、「蔥多」、「酥脆一點」快捷標籤與自由填寫欄位。

3. **點單派送與多元輸出**
   - **📧 Email 派發**：點擊「確認送出並寄信」自動封裝訂單結構發送至指定信箱 `Liao.Howard@gmail.com`。
   - **📋 LINE 明細複製**：一鍵複製格式化文字點單，方便於社交軟體傳送。
   - **🖨️ 熱感小票列印**：內建專屬列印樣式（Print CSS），支援出單機與標準紙張輸出。
   - **💾 本地草稿暫存**：透過 `localStorage` 即時儲存點單進度，重整頁面不遺失資料。
