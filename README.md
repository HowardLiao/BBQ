## ✨ 核心特色與功能 (Features)

1. **唯一訂單編號 (Unique Order ID)**
   - 每次下單自動生成唯一訂單識別碼（格式：`BBQ-當日日期-當前時間`，例：`BBQ-20260821-104523`）。

2. **動態 QR Code 即時掃描**
   - 點餐收據右上角動態生成 QR Code。手機掃描後可立即讀取該筆訂單之完整明細、單號、辣度、用餐方式與統計總額。

3. **數值與價格嚴格靠右對齊 (Tabular Alignment)**
   - 點餐清單與熱感收據之「單價」、「數量」、「小計」均採等寬數值嚴格靠右對齊，排版俐落清晰。

4. **系統架構師互動聯絡卡**
   - 點擊標題或收據下方的 `Designed by Howard Liao, Ph.D.` 即跳出專屬聯絡資訊彈窗，顯示電話 `0975-323-161`、信箱並支援一鍵撥打與號碼複製。

5. **完整菜單與即時計算**
   - 涵蓋嚴選肉品、海鮮類、鮮甜時蔬、經典串燒/豆製品、飲品酒類等 30 項人氣品項。
   - 每品項支援即時數量調整（+/- 按鈕與手動輸入），自動計算品項小計與全單總計。

6. **點單派送與多元輸出**
   - **📧 Email 派發**：點擊「確認送出並寄信」自動封裝訂單結構發送至指定信箱 `Liao.Howard@gmail.com`。
   - **📋 LINE 明細複製**：一鍵複製格式化文字點單，方便於社交軟體傳送。
   - **🖨️ 熱感小票列印**：內建專屬列印樣式（Print CSS），支援出單機與標準紙張輸出。
   - **💾 本地草稿暫存**：透過 `localStorage` 即時儲存點單進度，重整頁面不遺失資料。
